# 과잉집사 사운드 설계 V1

앱에는 아직 연결하지 않은 검수용 후보군이다. 소리는 관계 경험을 보조하되, 모든 동작에 붙여 소란스럽게 만들지 않는다.

## 적용 원칙

- 한 번의 조작에는 소리 하나만 재생한다.
- 자동 재생하지 않는다.
- 버튼과 고양이 탭은 같은 소리를 쓰지 않는다.
- 날카로운 고음, 손뼉·싸대기처럼 들리는 강한 어택, 과한 저음을 피한다.
- 실제 연결 시 사용자의 사운드 설정을 따른다.

## 후보 목록

| 분류 | 역할 | 후보 |
|---|---|---|
| 일반 버튼 | 주요 CTA와 확인 버튼 | A 부드러운 나무 버튼, B 종이 탭, C 말랑 팝, D 두 음 확인 |
| 고양이 탭 | 캐릭터를 직접 눌렀을 때의 생물감 | A 작은 므릉, B 골골 인사, C 궁금한 짹, D 앞발 인사 |
| 종이·서류 | 서류 열기, 작성, 내려놓기 | A 서류 펼침, B 연필 사각, C 종이 내려놓기 |
| 도장·완료 | 일정 완료, 접수 완료 | A 말랑 고무도장, B 둥근 승인도장, C 작은 처리 완료 |
| 선물·해금 | 드문 보상과 관계 흔적 | A 따뜻한 선물벨, B 작은 반짝임, C 봉인 해제 |
| 조명 | 스탠드 켜기·끄기 | A 부드러운 스위치, B 둥근 삑, C 두 번 토글 |

## 실제 연결 권장 범위

- 일반 버튼과 하단 내비게이션은 같은 계열을 공유하되 내비게이션 볼륨을 더 낮춘다.
- 고양이 탭은 전용 소리만 사용한다. 대사가 바뀌는 순간과 함께 재생한다.
- 종이 소리는 서류형 화면을 열거나 접수할 때만 사용한다.
- 도장은 완료가 확정된 순간에만 사용한다.
- 선물·해금은 자주 재생하지 않는 특별 보상으로 남긴다.
- 조명은 실제 스탠드 상태가 바뀔 때만 재생한다.

## 1차 추천

- 일반 버튼: A `button-soft-wood.mp3` 또는 B `button-paper-tab.mp3`
- 고양이 탭: A `cat-mrrp-soft.mp3` 또는 B `cat-purr-pip.mp3`
- 완료 도장: A `stamp-rubber-soft.mp3`
- 조명: A `lamp-soft-switch.mp3`

## 최종 선택 V2

- 일반 버튼·하단 메뉴: A `포근한 이동`
- 고양이 터치: A `작은 므르릅` / B `응냥` / D `코 인사`
- 도장·완료: C `작은 처리 완료`
- 선물: A `따뜻한 선물`
- 관계 단계 해금: D `봉인 해제`
- 선택하지 않은 종이·클립·골골·조명 동작은 기존 V1 합성을 유지한다.

### 연결 규칙

- 고양이 터치는 세 후보를 번갈아 사용한다. 네 번 이상 연타해 귀찮은 표정이 나온 경우에는 가장 낮고 짧은 `코 인사`만 사용한다.
- 높은 관계에서 드물게 나오는 기존 골골은 다른 고양이 터치음과 겹치지 않고 그 탭의 단독 반응으로 사용한다.
- 일반 선물은 `따뜻한 선물`, 선물로 관계 단계가 오른 순간은 `봉인 해제`만 재생한다.
- 음원은 24kHz 모노 MP3 32kbps, 활성 구간 RMS 약 -20dBFS, 피크 -3dBFS 이하를 기준으로 한다.
