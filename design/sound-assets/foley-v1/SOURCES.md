# Foley v1 sources

All files in this directory were downloaded from Mixkit's free sound-effects library on 2026-08-24 and are covered by the Mixkit License:

- https://mixkit.co/license/#sfxFree
- https://mixkit.co/free-sound-effects/click/
- https://mixkit.co/free-sound-effects/paper/
- https://mixkit.co/free-sound-effects/office/
- https://mixkit.co/free-sound-effects/pop/
- https://mixkit.co/free-sound-effects/slide/

Processing: leading silence removal, loudness normalization to -22 LUFS with -2 dB true-peak ceiling, mono 44.1 kHz, 96 kbps MP3, and short end fade. The `raw/` downloads are working files and are not part of the committed asset set.
