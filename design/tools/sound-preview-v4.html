효과음 비교 v4

전자음 후보 폐기. 현재 앱 소리와 실제 물성 기반 후보를 같은 자리에서 비교합니다.

고양이 음성은 수정 대상 아님.
자동 재생 없음. 각 버튼은 한 번에 한 소리만 재생합니다.

1. 일반 버튼 · 하단 메뉴

화면 이동과 작은 버튼을 누를 때

2. 말풍선 종이

장면에서 종이 찢는 듯 들렸던 누락 항목

3. 클립 · 서류 고정

종이 카드와 브리핑 서류가 나타날 때

4. 결과서 큰 도장

대업 결과서와 공식 판정

5. 브리핑 완료 도장

오늘 할 일을 완료했을 때

6. 선물 전달

고양이에게 선물을 직접 건넬 때

7. 관계 해금

새 관계 기록이나 보관함이 열릴 때

새 후보 원본: Mixkit 무료 SFX 라이선스. 비교용으로 시작 무음 제거, 모노 44.1kHz, 96kbps, 평균 음량 정리만 적용.
