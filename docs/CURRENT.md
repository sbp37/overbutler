## CURRENT WORK

**BUTLER / MANAGER 단순화.** CAT-FIRST 단계에서 집사 화면은 "여러 집사를 관리하는
인사관리 화면"이 아니라 "지금 내 고양이가 어떤 애고, 우리 관계가 어디까지 왔는지"를
보는 화면이다.

390px 첫 화면에 들어가야 하는 것: 고양이 얼굴 → 이름 → **관계 문장** → 관계 단계 →
선물 CTA. roster / 근무 기록 / 모집 / 담당 변경은 전부 fold 아래.

- **관계 문장이 숫자보다 먼저.** `#relationship-stage-summary`는 시스템 설명문 대신
  `relationshipStageLine()`의 캐릭터 대사를 쓴다. 과몰입 수치·게이지는 그 아래로 내렸다.
- **선물은 관계 행동이다.** `#give-gift-button`을 근무 기록 카드 안에서 꺼내
  관계 바로 다음에 뒀다. 선물 로직·가격·오버레이는 건드리지 않았다.
- roster / 신규 지원 / 담당 변경은 순서만 아래로 내린 secondary 영역이다. 기능은 그대로다.
- "관계가 깊어질수록 반응이 더 커집니다" → "관계가 깊어질수록 숨기던 마음이 조금씩
  들킵니다". **관계 상승 = 볼륨 상승 카피는 이 화면에도 두지 않는다.**
