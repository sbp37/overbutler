## CURRENT WORK

**BUTLER DIARY 단순화.** 집사 일기는 보관함의 또 다른 탭이 아니라 "내가 오늘 한 말을
고양이가 뒤에서 뭐라고 적어놨을까"가 궁금해서 다시 들어오는 화면이다.

일기 모드(`[data-archive-mode="diary"]`)의 시각 순서:

```
집사 한 줄 상태  →  집사 일기 / 날짜  →  탭  →  intro(2줄)
  →  오늘의 봉인 일지(teaser)  →  공개된 일기들  →  통계
```

- **공개 로직은 절대 건드리지 않았다.** 오늘 것은 teaser만, 다음 날짜에 전체 공개,
  legacy 일기(`diaryRevealVersion === 0`)는 계속 공개. `sealed` 판정식과
  `unlockPastDiaryEntries()`에 손대지 않는다. localStorage schema 변경 없음.
- 큰 집사 초상화는 기록 모드와 같은 54px 한 줄로 접었다. 그 한 줄은 보관량만 말한다 —
  "오늘 뭘 적는 중"은 teaser가 이미 말하므로 중복하지 않는다.
- 통계(`.diary-ledger-summary`)는 일기 아래로 내렸다. 일기 화면은 대시보드가 아니다.
- 일기 모드에서 `기록` 탭은 접는다(하단 nav와 중복). `공식 인증서` 탭은 유지.
- 빈 화면은 "일기 없음"으로 끝내지 않고, 무엇을 하면 일지가 생기는지 알려준 뒤
  홈으로 돌아가는 버튼을 준다. 이 버튼은 렌더할 때마다 새로 만들어지므로
  `#butler-diary-list`에 클릭을 위임해 둔다(초기 `$$("[data-view]")` 바인딩에 안 걸림).

## 방향에서 벗어나는 것

- 생산성/투두 앱으로 만들지 않는다. 과잉집사는 사소한 일을 국가 대업으로 접수하는
  관공서 세계관이다 — 체크리스트 앱처럼 담백해지면 방향을 벗어난 것이다.
- 남아 있는 정리 대상(별도 패스): `grade` 라벨(`인류사적 대업`·`우주 최초 기록`)은 기록에
  저장되는 공용 값이라 그대로 뒀고, AI·외계인 대사 풀은 아직 새 VOICE 기준으로 정리하지
  않았다.
