## CURRENT WORK

**GLOBAL RETRO VISUAL UNIFICATION.** HOME(접수처)을 기준으로 나머지 화면을 같은
사무국의 다른 부서처럼 보이게 맞춘다. 기능·구조·문구는 건드리지 않는 외관 전용 패스다.

공통 언어는 `retro-office.css` 한 파일에 모았다 (HOME은 `home-office.css` 그대로,
이 파일은 `#view-home`을 건드리지 않는다):

```
격자 종이 23px · 이중선 머리글 · 각진 모서리 3~5px
하드 오프셋 그림자 · 점선 구분선 · burgundy 행정 라벨
```

부서마다 성격은 다르게 둔다. **"모든 화면에 버건디 박스 붙이기" 식 획일화는 금지.**

| 화면 | 성격 |
|---|---|
| HOME | 접수처 (기준, 수정 금지) |
| RECORDS | 기록보관과 — 캐비닛에서 뽑은 접수 카드, 색인 칸, 조용한 분류 도구 |
| DIARY | 비밀 관찰 일지 — 조금 더 낡은 종이, 일부인, 봉인된 미개봉 서류 |
| MANAGER | 중앙인사국 — 인사기록카드 + 관찰란(비고) + 사내 전달 접수 |
| WEEKLY | 주간 보고서 — 문서 머리 띠, 보고서 번호, 결재 의견란 |
| FORM05 | 심사 결과서 — 서식 번호, 종이, 도장 |
| **FORM04** | **제외.** 어두운 분석실로 튀는 게 의도다 |
| CERTIFICATE | 최소 조정만 (이미 공식 문서로 읽힘) |

  저장되는 공용 값이라 그대로 뒀고, AI·외계인 대사 풀은 아직 새 VOICE 기준으로 정리하지
  않았다.
