# CURRENT

지금 이 저장소에서 개발을 이어갈 때 먼저 맞춰야 할 방향. `docs/PROJECT.md`(제품 개요),
`docs/BUTLER-VOICE.md`(대사 규칙)와 함께 작업 전에 읽는다.

## 현재 기준

- **개발 기준은 CAT-FIRST.** 고양이 집사 하나를 완성도 있게 만드는 것이 우선이고,
  다른 캐릭터(AI/강아지/좀비/아이돌/엘프/마녀/요정/외계인/닌자)는 기존 기능이
  깨지지 않게만 유지한다. 당분간 확장 고려 대상이 아니다.
- **화면 하나씩 완성한다.** 여러 화면을 동시에 손대지 않는다.
- **HOME은 디자인 승인 방향이므로 잠긴 상태.** `home-office.css`와 HOME 레이아웃
  (파일철/도장/집사방/빠른 입력/bottom nav)은 명시적 요청 없이 재디자인하지 않는다.
- **현재 focus = HOME INPUT UNDERSTANDING.** 입력/응답 로직을 고칠 때는
  `docs/INPUT-ROUTING.md`를 먼저 읽는다.
- **생산성/투두 앱으로 만들지 않는다.** 과잉집사는 사소한 일을 국가 대업으로
  접수하는 관공서 세계관이다 — 체크리스트 앱처럼 담백해지면 방향을 벗어난 것이다.
