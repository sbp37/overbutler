## CURRENT WORK

**RECORDS 단순화.** 기록 탭이 "보관함 관리 화면"이 아니라 "내가 집사에게 말했던 것들이
쌓여 있는 곳"으로 보이게 한다.

기록 모드(`[data-archive-mode="records"]`)의 시각 순서를 이렇게 고정한다:

```
집사 한 줄 상태  →  오늘의 기록 / 날짜  →  탭  →  실제 기록 목록
  →  범례  →  오늘 요약  →  필터  →  검색·등급
```

- 큰 집사 초상화 카드는 기록 모드에서만 한 줄(54px)로 접는다. 집사를 없애는 게 아니라
  기록보다 앞에 세우지 않는 것이다. diary / certificates 모드는 그대로 큰 카드다.
- 필터·검색·등급은 **기능을 지우지 않고** 목록 아래로 내리고 작게 만든다.
  DOM 순서는 그대로 두고 flex `order`로만 바꿔 필터 로직에 손대지 않는다.
- 기록 모드에서 `집사 일기` 탭은 접는다(하단 nav와 중복). `공식 인증서` 탭은 여기 말고
  진입로가 없으므로 유지한다. diary 모드로 가면 탭은 다시 3개로 돌아온다.

## 방향에서 벗어나는 것

- 생산성/투두 앱으로 만들지 않는다. 과잉집사는 사소한 일을 국가 대업으로 접수하는
  관공서 세계관이다 — 체크리스트 앱처럼 담백해지면 방향을 벗어난 것이다.
- 남아 있는 정리 대상(별도 패스): `grade` 라벨(`인류사적 대업`·`우주 최초 기록`)은 기록에
  저장되는 공용 값이라 그대로 뒀고, AI·외계인 대사 풀은 아직 새 VOICE 기준으로 정리하지
  않았다.
