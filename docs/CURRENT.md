**OWNER FILE — 보관함 통합.** 기록·집사 일지·인증서 세 탭을 "주인님 파일" 한 문서로
접었다. 화면을 더하지 않고 셋을 하나로 줄이면서, "관공서가 나에 대한 파일을 두껍게
키워간다"는 경험을 만든다.

```
표지        PERSONNEL FILE · 주인님 파일
            파일 두께 · 함께한 날 · 최다 대업 · 공식 인정 + 집사 소견 한 줄
필터 칩     전체 · 오늘 · 공식 인정 · 반복
날짜 그룹   구분선 → 기록 카드들 → 여백 메모(그날 일지)
            오늘 일지는 봉인 teaser, 지난 일지는 공개된 소견
지연 렌더   최근 14일 즉시 · 이전은 "이전 기록 펼치기"
검색        하단 유지
```

표지 수치는 전부 기존 state에서 파생 계산한다. 저장 계약에 새 키를 넣지 않았다.

**감시/기억 경계 원칙** — 유저가 제출한 내용에 대한 통계는 기억이라 쓰고(최다 대업,
총 기록 수, 함께한 날), 행동 패턴에 대한 통계는 감시라 쓰지 않는다(접수 시간대,
공백일, 부재 언급, 스트릭). 표지 소견도 이 경계를 지킨다.

하단 nav는 3칸이다 — 홈 / 파일 / 집사. 탭을 없앴으므로 nav에도 탭이 남지 않는다.

**FORM 04는 더 이상 어두운 분석실이 아니다.** 2026-08-17 사용자 승인으로 "다크는
의도적"이라는 이전 결정을 대체하고, 낮 종이 톤의 **대업 심사표**로 바꿨다 — 접수한
문장을 그대로 인용하고, 심사 항목에 도장이 위에서부터 차례로 찍히며, 심사 중인 칸만
점선 원이 천천히 돈다. 어두운 연출은 처음 한두 번만 즐겁고 그 뒤로는 매일 통과해야
하는 관문이었다. 기다리는 동안 읽을 것(집사의 육필 혼잣말)이 생기는 쪽을 택했다.

까지 들어가 세 기둥의 구조가 전부 완성됐다. 유료 상품 자체의 설계(가격·SKU·결제)는
오너 결정 사항으로 남아 있다. 남은 것:

**1. 첫 주 실사용 QA (end-to-end).** 신규 사용자가 첫 주에 실제로 겪는 흐름을
처음부터 끝까지 따라가며 남은 거친 부분을 찾는다. 이해 레이어 수정과 새 말투가
실제 입력에서 어떻게 버티는지가 핵심이다.

**2. 접수대 표정은 붙었다(2026-08-19).** `annoyed` / `happy` / `surprised` 세 장이
들어와 base·blink와 함께 다섯 장이 됐다. 세 장 모두 base에서 얼굴만 바뀐 것이라
몸·책상·조끼는 픽셀 단위로 동일하다(y≥700 변경 0px). 규칙: 표정은 잠깐 지나가고
반드시 base로 돌아오며, 표정이 떠 있는 동안에는 자동 깜빡임을 멈춘다.
- annoyed — 3초 안에 이어진 세 번째 탭부터. "또?"이지 "짜증"이 아니다.
- happy — 대업 판정을 확인하고 방으로 돌아온 순간, 그리고 선물 수령 후 첫 귀가.
- surprised — 파워·희귀 판정으로 돌아온 순간.
표정은 방이 다시 보이는 시점에 예약 재생한다. 판정 화면이 방을 통째로 덮기 때문에
그 자리에서 얼굴을 바꾸면 아무도 못 본다.
