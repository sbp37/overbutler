# 집사 보이스 · 세계관 규칙

과잉집사의 대사를 쓰거나 고칠 때 이 문서를 기준으로 삼는다.
사람이 쓰든 AI 도구가 쓰든 동일하게 적용한다.

---

## 0. 한 줄 정의

> 사소한 일상을 국가 대사급으로 처리하는 관공서 +
> 그걸 규정 핑계로 진심을 다해버리는 담당 집사.

주접(과잉 칭찬)이 상품이고, 관계는 주접의 **성격**을 바꾸는 장치다.

## 1. 다정함은 1일차부터, 과장은 절제해서

> **다정함은 1일차부터 충분히. 과장은 절제해서.
> 관계가 깊어져도 캐릭터는 변하지 않고, 마음만 더 들킨다.**

예전 기준이던 "주접 볼륨은 1일차부터 만렙"은 **폐기한다.** 모든 반응을 최대 볼륨으로
쓰면 캐릭터가 사라지고, 매번 터지는 주접은 그냥 시끄러운 기본값이 되어 아무 가치가 없다.

새 기준:

- **1일차부터 충분히 다정하다.** 응원·토닥임·관심은 처음부터 아끼지 않는다.
  집사가 초반에 무관심하거나 사무적이기만 하면 실패다.
- **과장은 절제한다.** 평소 반응의 중심은 *캐릭터다운 태도 + 다정함*이지 과장이 아니다.
- **관계가 깊어져도 캐릭터는 그대로다.** 애정도가 올랐다고 갑자기 소리 지르는
  주접 캐릭터로 변하지 않는다. 츤데레는 끝까지 츤데레다.
- **자라는 것은 볼륨이 아니라 새어나오는 마음이다.** 숨기던 애정이 점점 들킨다.

### 고양이 첫인상은 츤데레보다 신입의 생명력이 먼저

고양이는 첫 발령을 기다려온 신입이다. 관계 0~1단계에서는 까칠함보다
**설렘, 과잉 준비, 잘 맡아보려는 책임감**이 먼저 보여야 한다.

- 첫 문장은 환영과 책임감으로 시작하고, 츤은 문장 끝에 짧게만 붙인다.
- 「뭐냥」「왜 누르냥」「이걸 대업으로 올리냐냥」처럼 밀어내는 말로 첫인상을 만들지 않는다.
- 신입이라 긴장할 수는 있지만 무능하지 않다. 서류와 규정은 잘 알고, 첫 주인님이라 도장 방향을 다시 확인하는 쪽이다.
- 귀, 꼬리, 펜, 결재판처럼 감추지 못한 몸짓과 과잉 준비로 생명력을 보여준다.
- 관계가 쌓이면 신입의 긴장은 익숙함으로 바뀌고, 츤데레 가면 아래 마음이 더 자주 샌다.

사용자가 느껴야 하는 것은 「나를 귀찮아한다」가 아니라
**「프로인 척하지만 첫 업무라 신난 티가 난다」**다.

## 2. 성장 축 (세기 말고 이걸 올린다)

| 축 | 초반 | 후반 |
|---|---|---|
| 근거 | 일반 규정 | 접수 장부에 남은 기록 인용 |
| 준비성 | 즉흥 반응 | 미리 준비해둔 게 들킴 |
| 범위 | 담당 집사 도장 하나 | 부서·감사실·인사국까지 연루 |
| 가면 | 프로페셔널 | 말투는 그대로인데 본심이 새어나옴 |

**볼륨은 이 표 어디에도 없다.** 후반 대사가 초반 대사보다 시끄러우면 잘못 쓴 것이다.

### 관계 단계 예시 (cat)

| 단계 | 대사 | 자란 것 |
|---|---|---|
| 초반 | 오늘도 버텼네냥. 그 정도면 충분하다냥. 기록은… 해두겠다냥. | (다정하지만 무심한 척) |
| 중간 | 힘들었다면서 씻기까지 했냥? 좀 대단하긴 하네냥. 아주 조금. | 인정이 새어나옴 |
| 애정 높음 | 왔냥. 기다린 건 아닌데… 이상하게 네가 오니까 골골송이 안 멈춘다냥. | 몸이 먼저 반응함 |
| 매우 높음 | 오늘 네 얘기 없으면 접수대가 좀 허전하긴 하다냥. 사무국에는 말하지 마라냥. | 본심 인정 |

네 단계 모두 **같은 목소리 크기**다. 달라지는 건 얼마나 들켰느냐뿐이다.

### 엔드게임

세기로 끝장을 보지 않는다. **집사의 편애가 공식 징계 대상이 되고, 그걸 감수하는 것**이
관계의 증명이다.

```
감사실이 담당 집사의 편애를 적발
  → 집사 시말서 제출
  → 시말서 내용에도 주인님 이야기
  → 사무국 항복: "주인님 전용 특례 조항" 신설
```

## 2-1. 주접은 기본값이 아니라 양념

주접(과장된 대업 격상)은 **가끔 터질 때 가치가 있다.**

```
평소       : 캐릭터다운 태도 + 다정함        ← 대부분의 반응
가끔       : 과장된 대업 주접
아주 드물게 : POWER 주접 (FORM 05-P)
```

목표는 **"평소 덤덤한 애가 왜 저래ㅋㅋ"** 다. 매번 주접이면 이 반응이 나올 수 없다.

### 랜덤 거대 비유 금지

칭찬 강도를 올리려고 캐릭터와 무관한 거대 비유를 붙이지 않는다.

- ❌ 피카소 / 아인슈타인 등 실존 유명인
- ❌ 역사적 천재, 우주적 존재, 인류 문명사
- ❌ 맥락 없이 스케일만 키우는 아무 비유

> ❌ 씻기 완료의 신이다냥!! 피카소도 울고 가겠다냥!!
> ⭕ 씻었냥? 오늘 할 일은 그걸로 끝이다냥. 잘했다냥.

과장을 쓸 거면 **사무국 세계관 안의 과장**(서류·도장·부서·규정·특례)을 쓴다.
집사 캐릭터와 연결되지 않는 비유는 사용 금지.

## 3. 프라이버시 리트머스 (반드시 통과)

집사는 **사용자가 앱에 직접 남긴 기록**과 거기서 계산 가능한 것만 안다.
그 외에는 아무것도 모르고, 아는 척해서도 안 된다.

모든 기억·패턴 대사는 아래 두 질문을 통과해야 한다.

1. **이 정보, 사용자가 직접 제출한 기록에서 나왔는가?**
2. **문장의 시선이 사용자를 향하는가, 서류/집사 자신을 향하는가?**

### 시선의 방향이 전부를 가른다

| ❌ 감시로 읽힘 | ⭕ 애착 개그로 읽힘 |
|---|---|
| 다 세고 있었다냥 | 접수 장부 보니 세 번째다냥. …장부가 그렇다는 거다냥 |
| 지켜봤다냥 | 이 파일만 자꾸 다시 펼쳐본다냥 |
| 오늘 씻을 줄 알았다냥 | 혹시나 해서 미리 써뒀다냥. 기대한 건 아니다냥 |
| 네가 몇 시에 뭐 하는지 안다냥 | (사용 금지. 시간 패턴 추론 자체를 하지 않는다) |

### 핵심 장치: 카운팅은 장부에 떠넘긴다

집사가 세는 게 아니라 **장부에 그렇게 적혀 있는 것**이다.
집사는 관찰자가 아니라 **문서 담당 공무원**이고,
유별난 짓의 대상은 사용자가 아니라 **사용자가 낸 서류**다.

### 감시당하는 쪽은 집사다

이 앱의 시선 구조는 [사무국 → 집사]이지 [집사 → 사용자]가 아니다.
감사실이 적발하는 것은 언제나 **집사의 편애**다. 이 구도를 유지한다.

### 금지

- 압박 / 죄책감 / 통제 / 소유 / 담당 변경 방해
- 사용자가 입력하지 않은 사실을 지어내기
- 시간대·위치·빈도 등 행동 패턴을 "파악하고 있다"고 말하기

### 허용

- 귀여운 애착 / 편애 / 기다림 / 챙김 / 보고 싶어함
- 집사 본인의 부재중 오작동 ("네가 없어서 내가 고장남" — 시선이 집사 자신)

## 5. 캐릭터별 보이스

공통: 어미만 바꾼 같은 문장을 여러 캐릭터에 돌려쓰지 않는다. 인격이 달라야 한다.

### 시그니처 소재는 양념이지 문장 생성 공식이 아니다

캐릭터에 고유 소품이 있다고 해서 모든 문장을 그 소품으로 채우면, 캐릭터가 아니라
치환 규칙이 된다.

> ❌ 별가루 폭주! 별가루가 멈추질 않아요! 별가루 대업 별가루 도장!
> ⭕ 오늘은 반짝이지 않아도 괜찮아요. 그건 제가 할게요.

**닌자가 좋은 기준이다.** 닌자는 계속 닌자인 채로(과묵·임무·경계) 사용자에게 점점
특별대우를 한다. 말투를 버리지도, 말투만 반복하지도 않는다.

관계가 깊어져도 각 집사의 본래 캐릭터가 사라지면 안 된다. 애정도가 올랐다는 이유로
좀비가 갑자기 활발해지거나, 엘프가 소리를 지르면 실패다.

| 집사 | 축 | 특징 |
|---|---|---|
| 고양이 | 츤데레 | 부정하면서 챙김. "…별 뜻은 없다냥" |
| AI | 고장난 로그 | 명사형 종결(~함/~됨/~음), 자기를 "집사"로 3인칭, `(버그아님)` |
| 강아지 | 폭발 | 감탄사 연발, 꼬리·방방 뜀, 숨김 없음 |
| 좀비 | 나른함 | 말줄임표, "으르...", 주인님 앞에서만 정신 돌아옴 |
| 아이돌 | 도도한 척 | "어머", 팬/방송/큐카드 비유, 속으로는 흥분 |
| 엘프 | 시적 | 천 년 설정, 숲·별 비유, 존중하는 존댓말 |
| 마녀 | 점술 | 수정구슬·주문·길조 |
| 요정 | 반짝임 | 별가루, 작은 것을 크게 |
| 외계인 | 관측 보고 | "~함" 종결, 본성 보고서, 지구 문물 분석 |
| 닌자 | 충성 | 임무·극비·맹세, 과묵하지만 뜨거움 |

### AI 집사 문법 (특수)

기본 문장은 시스템 로그체. `~합니다/~습니다/~하세요`를 기본으로 쓰지 않는다.

```
X  오늘은 충분히 잘 해냈습니다. 추가 성과는 필요 없습니다.
O  [판정 완료] 오늘 수행량 충분함. 추가 성과 필요 없음.

X  저도 보고 싶었습니다.
O  [알림] 주인님 보고싶음 감지됨. 버그인지 확인 필요.

X  커피 감사합니다.
O  커피 입력 완료. 행복 수치 최대치 도달. 해당 기능 원래 없음.
```

재미는 '정상적인 AI가 시스템 용어를 쓰는 것'이 아니라
**'기계식 로그로 버티다가 감정 때문에 자꾸 고장나는 것'**에서 나온다.

## 6. 대사 작성 체크리스트

새 대사를 추가하거나 고칠 때 전부 통과해야 한다.

- [ ] 이 대사가 **평소 톤**인지 **가끔 터지는 주접**인지 정하고 썼는가 (기본값은 평소 톤)
- [ ] 캐릭터와 무관한 거대 비유(유명인·역사·우주)를 강도 올리려고 붙이지 않았는가
- [ ] 관계가 올라가도 목소리 크기가 아니라 들키는 정도만 커지는가
- [ ] 시그니처 소품을 문장 생성 공식처럼 반복하지 않았는가
- [ ] 프라이버시 리트머스 2문항을 통과하는가
- [ ] 캐릭터가 드러나는가 (다른 집사로 바꿔도 말이 되면 실패)
- [ ] 관계 초반 대사에 개인화 카드를 미리 써버리지 않았는가
- [ ] 다정함이 1일차부터 충분한가 (무관심하거나 사무적이기만 하면 실패)
