개인정보 처리방침

시행일 2026.08.09 · 현재 공개 웹 버전 기준

과잉집사는 회원가입이나 자체 서버 저장 없이 작동합니다. 주인님 호칭과 대업 기록은 기본적으로 사용 중인 기기의 브라우저 저장공간에만 보관됩니다.

1. 처리하는 정보와 목적

기기 내 기록
주인님 호칭, 대업·일지·인증서, 담당 집사, 관계 단계, 포인트·선물·해금 상태
처리 목적
앱 진행 상태 복원, 캐릭터별 반응 제공, 기록·인증서 다시 보기
저장 위치
사용 중인 기기 내부 저장소

운영자는 위 기기 내 기록을 별도 서버로 전송하거나 조회하지 않습니다. 대업 내용과 호칭을 포함하는 외부 분석 이벤트도 전송하지 않습니다.

2. 웹 접속 과정에서 처리될 수 있는 정보

서비스 제공과 보안을 위해 호스팅 사업자 또는 글꼴 전송 사업자가 IP 주소, 브라우저·기기 정보, 요청 시각, 요청 URL 같은 접속 정보를 자동 처리할 수 있습니다.

호스팅
Vercel · 웹 파일 전송, 보안, 장애 대응
글꼴 전송
Google Fonts, jsDelivr · 화면용 웹 글꼴 제공
보유 기간
각 제공 사업자의 정책과 보안 목적에 따른 기간

현재 버전은 광고 SDK, 계정 SDK, 위치정보, 연락처, 카메라, 마이크를 사용하지 않습니다.

3. 제3자 제공·처리위탁·국외 처리

운영자가 이용자의 대업 기록을 제3자에게 판매하거나 제공하지 않습니다. 다만 웹 호스팅과 글꼴 전송 과정에서 위 사업자의 국외 서버를 거쳐 접속 정보가 처리될 수 있습니다. 구체적인 처리 위치와 기간은 각 사업자 정책을 따릅니다.

4. 보유 기간과 삭제 방법

기기 내 기록은 이용자가 브라우저의 사이트 데이터 또는 앱 데이터를 삭제할 때까지 유지됩니다. 앱을 삭제하거나 브라우저 저장공간을 초기화하면 복구할 수 없습니다.

  1. 브라우저 설정에서 ‘사이트 데이터’ 또는 ‘저장공간’을 엽니다.
  2. 과잉집사 사이트의 데이터를 삭제합니다.
  3. 삭제 후 앱을 다시 열면 처음 상태로 시작합니다.

5. 공유 기능 이용 시

인증서 공유를 선택하면 기기의 운영체제 공유 기능 또는 이용자가 선택한 외부 앱으로 이미지와 문구가 전달됩니다. 전달 이후에는 선택한 외부 서비스의 개인정보 정책이 적용됩니다. 공유는 이용자가 버튼을 누른 경우에만 시작됩니다.

6. 안전성 확보와 이용자 권리

기록은 서버 계정이 아닌 기기 저장공간에 보관하며, 저장 실패 시 마지막 정상 상태를 유지하도록 처리합니다. 이용자는 사이트 데이터를 삭제해 기기 내 기록을 직접 제거할 수 있습니다.
